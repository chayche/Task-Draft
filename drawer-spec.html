Задачи — дровер задачи

Спецификация для внедрения в платформу Efir · по прототипу Chefir-Web (tasks/) · 09.10.2026

Открытая задача показывается в дровере: закруглённой со всех углов панели, которая выезжает справа поверх доски. Доска под ним не сжимается. Внутри: шапка с действиями, название и описание (правятся по клику), свойства, вкладки «Комментарии / История / Файлы / Связи» и поле комментария.

1. Расположение и размеры

Задача завершена

Схема. Слева панель досок, справа доска. Дровер прижат к правому краю доски с отступом 8 px со всех сторон.

ПараметрЗначение
Где лежитВ той же ячейке грида, что и доска (grid-column: 2; grid-row: 1; justify-self: end), над ней (z-index: 6). Не отдельная колонка: доска не сжимается.
Ширинаmin(460px, 100% − 16px). 460 — максимум при любой ширине окна. Ручки изменения ширины нет.
Отступы8 px со всех сторон от краёв доски (margin: 8px). Отступ справа сохраняется при любой ширине окна.
Скруглениеcalc(var(--panel-radius) − 4px): концентрично панели доски (панель 18–24 → дровер 14–20).
Тень0 0 0 1px rgba(0,0,0,.04), 0 12px 40px rgba(0,0,0,.14), 0 2px 8px rgba(0,0,0,.06)
Фонvar(--panel) (#FFFFFF; тёмная тема #212121)
Прокрутка доскиПока дровер открыт, у колонок доски padding-right: 476px (460 + 16): последнюю колонку можно докрутить из-под дровера. В аналитике отступа нет, дровер просто лежит поверх контента.

Адаптив

ШиринаПоведение

Полоска чуть затемнена (rgba(0,0,0,.08)), любой тап по ней закрывает дровер, даже по карточке под ним. 56 px — зона нажатия с запасом (Apple 44 pt, Google 48 dp).

2. Появление и закрытие

ПараметрЗначение
Появлениеtransform: translateX(calc(100% + 16px)) → none, 360 мс, cubic-bezier(.22, 1, .36, 1); opacity 0 → 1, 160 мс ease
ЗакрытиеОбратно вправо, 360 мс, та же кривая; opacity 200 мс; visibility: hidden — после окончания (задержка 360 мс)
Смена задачи в открытом дровереДровер не переезжает. Тело проявляется со сдвигом: opacity 0 → 1, translateX(14px) → 0, 260 мс, cubic-bezier(.22, 1, .36, 1).
Reduced motionprefers-reduced-motion: reduce — без переходов

Открывают

  • Клик по карточке задачи (на доске, в списке, в смарт-списках)
  • «Открыть» в контекстном меню карточки
  • Ссылка на связанную задачу внутри дровера
  • «+» → «Создать задачу» (черновик, см. п. 5)

Закрывают

  • Крестик в шапке
  • Esc
  • Клик по доске мимо карточек и кнопок. Клик по другой карточке открывает её задачу
  • Телефон: тап по затемнённой полоске, «Назад» в шапке доски
  • Переход в «Аналитику» закрывает открытую задачу. Если создать задачу из аналитики, дровер откроется поверх неё.

5. Создание задачи

  • «+» в панели досок → «Создать задачу». Черновик встаёт первым в самую левую колонку текущей доски (не на доске — первой доски). Пока не сохранён, он нигде не виден: ни в колонках, ни в счётчиках, ни в аналитике.
  • Дровер открывается с теми же полями, что у существующей задачи. В названии стоит «Задача», выделено целиком (печать сразу заменяет). Описание пустое, подсказка «Добавьте описание».
  • Задача создаётся, как только сохранили непустое название: Enter, галочка, уход из поля, клик мимо дровера, крестик. Описание сохраняется вместе с ней.
  • Название стёрли и закрыли дровер, или открыли другую задачу — черновик удаляется.

7. Вкладки и комментарии

  • Сегменты «Комментарии / История / Файлы / Связи» со счётчиками, отступ сверху 26. По умолчанию открыты «Комментарии».
  • Лента комментариев — та же, что в обсуждениях чатов: баблы, аватары, даты «Вчера / Сегодня», разделитель «Непрочитанные». Счётчик на вкладке — только непрочитанные.
  • Поле комментария прижато к низу дровера (слева и справа по 12, снизу 10), над ним справа капсула «Саммари».

8. Мини-карточка на доске

Очень длинное название задачи, которое точно не поместится в две строки на мини-карточке канбан-доски
Описание задачи

Название на карточке — не больше двух строк, дальше многоточие: display: -webkit-box; -webkit-box-orient: vertical; -webkit-line-clamp: 2; overflow: hidden. Полное название видно в дровере. Открытая в дровере карточка подсвечена.

10. Доступность

  • Дровер — role="dialog", aria-label="Задача". Закрытый — visibility: hidden, недоступен с клавиатуры.
  • Поля названия и описания — contenteditable="plaintext-only", role="textbox", у описания aria-multiline="true"; у обоих aria-label.
  • Галочки — tabindex="-1": сохранение с клавиатуры — Enter.
  • После закрытия фокус возвращается на карточку задачи.
